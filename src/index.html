HOW TO USE

문제에 집중하고,
나의 페이스를 기록하세요.

  1. 이용 권한이 있는 PDF를 선택하고, 이번 모의고사의 PDF 시작·끝 페이지만 입력합니다. 책에 인쇄된 쪽수가 아닌 PDF 순서이며, 선택 범위를 고화질로 모두 준비합니다.
  2. 전체 모의고사는 5영역×20문제×15분, 영역별 연습은 선택한 1영역 20문제·15분입니다. 준비·휴식 시간은 전체 최대 75분에서 제외됩니다.
  3. 전체 시험의 자유 휴식 모드는 영역 사이 자유롭게 쉬고, 시작 버튼 뒤 5초 준비합니다. 실전 진행 모드는 영역 제출 뒤 30초 준비 후 다음 영역을 자동 시작합니다. 첫 영역은 두 모드 모두 5초 준비하며, 준비 중 PDF 위치를 맞출 수 있습니다.
  4. 답을 고르고 ‘답안 제출’을 누르면 다음 문제로 이동합니다. ‘문제 건너뛰기’를 눌러도 돌아갈 수 없습니다. 확정한 답과 헷갈림·찍었음 표시는 수정할 수 없으며, 다음 문제에서 메모장·그림판·계산기가 초기화됩니다.
  5. PDF 스크롤·페이지 이동 버튼은 답안 번호와 독립적으로 움직입니다. 계산기는 키보드 숫자·연산기호와 Enter 계산을 지원합니다. AC는 전체 지우기, ←는 한 글자 지우기입니다.
  6. 제한시간이 끝나면 선택 중인 답까지 자동 제출됩니다. 영역을 일찍 끝내려면 ‘현재 영역 조기 제출’을 누릅니다. 미도달 문제는 결과에서 구분됩니다.
  7. 일시정지 버튼은 시험 시간을 멈추고 PDF를 숨깁니다. 응시 중 사용안내를 열어도 시험·준비 시간이 멈추며, 안내를 닫으면 자동으로 이어집니다. 이미 일시정지한 시험은 안내를 닫아도 정지를 유지합니다.
  8. 새로고침·다른 페이지 이동·탭 닫기 시 시험·준비 시간이 자동으로 멈춥니다. 돌아오면 같은 PDF를 선택해 이어보고 ‘시험 재개’ 또는 ‘준비 재개’를 누르세요. 다른 탭을 보는 동안은 시간이 계속 흐릅니다.
  9. 등록 정답 세트는 자동 채점하고, 직접 입력을 선택한 시험은 종료 후 정답 입력 모달로 채점합니다. 결과의 ‘정답표 확인·수정’에서 정답을 고치거나 등록 세트를 선택해 재채점할 수 있습니다. 세트 변경 시 제목·유형 분석은 갱신하고 내 답·시간·표시는 유지합니다.
  10. 결과에서 정오답·시간·헷갈림·찍었음과 영역별 유형 분석을 확인하세요. 결과 복사로 노션에 붙이거나 CSV·PDF로 보관할 수 있습니다. 기록은 이 브라우저에만 저장되며 PDF 공유·자동 결과 전송은 없습니다.

새로고침·다른 페이지 이동·탭 닫기 시 시험과 준비 시간이 자동으로 멈춥니다. 다른 탭을 보는 동안은 시간이 계속 흐릅니다. 돌아오면 같은 PDF를 선택하고 재개해 주세요. 브라우저 강제 종료나 기기 전원 종료는 감지하지 못할 수 있습니다. 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다. PDF 공유·자동 결과 전송 기능은 없습니다.
