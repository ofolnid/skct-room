HOW TO USE

문제에 집중하고,
나의 페이스를 기록하세요.

  1. 이용 권한이 있는 PDF를 선택하고 과목별 페이지 범위를 입력합니다. 페이지는 책에 인쇄된 쪽수가 아닌 PDF 순서입니다.
  2. 선택 범위를 모두 준비한 뒤 시험을 시작합니다. 과목별 기본값은 20문제·15분입니다.
  3. 답을 고르고 ‘확정하고 다음’을 누르면 변경할 수 없습니다. PDF 페이지 이동은 답안 번호와 독립적입니다.
  4. 건너뛰어도 돌아갈 수 없습니다. 제한시간이 끝나면 선택 중인 답을 포함해 자동 제출됩니다.
  5. 저장된 정답표를 선택하거나 종료 후 직접 정답을 입력합니다. 정답표는 시험 중 화면에 표시하지 않습니다.
  6. 결과 복사로 노션 등에 붙이거나, PDF로 저장을 눌러 인쇄 창에서 PDF 저장을 선택합니다.

새로고침·탭 이동 중에도 제한시간은 계속 흐릅니다. 새로고침 후에는 같은 PDF를 다시 선택해야 합니다. 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다. PDF 공유·자동 결과 전송 기능은 없습니다.
